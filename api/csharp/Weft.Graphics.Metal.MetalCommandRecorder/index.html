    Class MetalCommandRecorder¶

    Namespace: Weft.Graphics.Metal
    Assembly: Weft.Graphics.dll

    A Metal command buffer being recorded. Metal has encoders where Vulkan has one command buffer: this opens the one the next command needs (render, compute or blit) and ends the one that is open. Metal does not order what a shader reaches through an address or an argument buffer, so the encoders form a chain, each waiting for a fence that the one before it updates: that is what the barriers of the render graph mean here (there are no image layouts to change, so does nothing by itself).

    public sealed class MetalCommandRecorder : CommandRecorder
