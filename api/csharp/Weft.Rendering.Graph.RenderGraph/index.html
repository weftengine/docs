    Class RenderGraph¶

    Namespace: Weft.Rendering.Graph
    Assembly: Weft.Rendering.dll

    One frame's rendering as a graph. Passes declare how they use images and buffers; culls the passes nothing depends on, shares memory between transients whose lifetimes do not overlap, and works out the barriers; runs the rest in the order they were added, each in a labelled, timed section. Build a new graph every frame: it is cheap, and the transients come from a that lives across frames.

    Remarks¶

    Images are tracked per mip level and array layer: a pass that declares a uses (and the graph transitions) just that part, so one pass can read a mip another is writing, and a mip chain or a cube map can be built a level or a face at a time. Transients may have several mips and layers, and are not multisampled.
