    Class WtexFile¶

    Namespace: Weft.Content.Textures
    Assembly: Weft.Content.dll

    A texture file on the common container (.wtex, with the magic WTEX): a META block ( and the index of the tail), the TAIL block with the small mip levels, smallest first, and the larger levels each in its own block MIP<n>, the smallest of them first in the file. The layout and its limits are in Docs/manual/content/formats.md.

    Remarks¶

    The file is untrusted. checks the container, then every number of META against the limits of , then that the blocks are exactly the ones META asks for with exactly the sizes it implies; nothing is allocated for a size before it has passed. The levels are read (and their checksums checked) when they are asked for. Everything wrong is a .

    ReadKtx2(string, ReadOnlySpan<byte>, WtexSettings?)¶

    A KTX 2 file as a texture: UASTC (with or without zstd), RGBA8, BC4, BC5, BC6H, BC7 or half-float RGBA, 2D, 3D, cube map or array. The levels are the bytes the KTX 2 file holds (libktx inflates the zstd supercompression of a file that has it); they are not decoded or encoded. ETC1S (BasisLZ) and zlib supercompression and every other format are refused.
