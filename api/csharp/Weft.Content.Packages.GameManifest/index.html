    Class GameManifest¶

    Namespace: Weft.Content.Packages
    Assembly: Weft.Content.dll

    The game.wgam at the root of a game folder: the game's name, who made it, its version, the folder of the player's files, its Steam app id, and the window it opens with. Checked against the engine's schema (Packages/game.xsd) and further: the version is major.minor.patch, and the paths it names (the entry scene and the icon) are relative and stay inside the game. A game without one still runs from a folder (it has no version and its user folder is named after the folder), but cannot be exported.
