    Class AssetFormats¶

    Namespace: Weft.Content.Assets
    Assembly: Weft.Content.dll

    The one table of the engine's file formats, read by everything that needs to know an extension or a magic: which files are authored assets, which are imported from what, which the editor lists by kind, which a hot reload watches, what a pack cooks. Docs/manual/content/formats.md describes each format; this table is what the code goes by. The built-in rows are registered when the table is first used; a library with a format of its own adds a row with . Safe to use from several threads.
